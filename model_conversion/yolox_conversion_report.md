# YOLOX Conversion Report

## Source
- ONNX: `app/src/main/assets/yolox_nano_retail_640_balanced_split_opset18.onnx`
- Old TFLite: `app/src/main/assets/yolox_nano_49cls_float16.tflite`
- New TFLite: `app/src/main/assets/yolox_nano_retail_640_balanced_split_fp16.tflite`

## Environment
- Python: 3.11.9
- venv: `.venv_model_convert`
- Packages used:
  - `onnx==1.19.1`
  - `onnxruntime==1.23.0`
  - `tensorflow==2.21.0`
  - `onnx2tf==1.28.8`
  - additional onnx2tf runtime deps: `tf-keras`, `onnx-graphsurgeon`, `psutil`, `ai-edge-litert`, `sng4onnx`

## Conversion
- Command: `onnx2tf -i app/src/main/assets/yolox_nano_retail_640_balanced_split_opset18.onnx -o model_conversion/yolox_saved_model -dsm -n`
- Output used: `model_conversion/yolox_saved_model/yolox_nano_retail_640_balanced_split_opset18_float16.tflite`
- Final copied asset: `app/src/main/assets/yolox_nano_retail_640_balanced_split_fp16.tflite`
- FP16 applied: yes, generated by onnx2tf float16 TFLite output
- Final size: 4,586,100 bytes

## Notes
- onnx2tf attempted ONNX optimization first and warned that optimization failed because the optional optimizer executable was unavailable.
- Earlier conversion attempts exposed missing Python deps; only the missing deps listed above were installed.
- onnx2tf's default sample-data download produced an invalid cache file in this environment. A local zero-valued float32 cache file was generated to let conversion continue.
- SavedModel was not retained as a commit artifact. onnx2tf produced usable float32/float16 TFLite files directly under `model_conversion/yolox_saved_model/`; that directory is intentionally excluded from commit.

## Compatibility
- Existing TFLite: input `[1, 640, 640, 3]`, output `[1, 8400, 54]`
- New TFLite: input `[1, 640, 640, 3]`, output `[1, 8400, 48]`
- New ONNX: input `[1, 3, 640, 640]`, output `[1, 8400, 48]`
- ONNX to TFLite parity passed on random sanity inputs with no NaN/Inf.
- Android postprocess can decode the new output as `4 box + 44 class scores`, but class label order/count needs confirmation.
